# RealMap — desktop app

Tauri 2 + SvelteKit + Svelte 5 + TypeScript + OpenLayers. What it does and how to use it:
[../README.md](../README.md). Building, testing and releasing: [../docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md).

```bash
npm install
npm run tauri dev    # run the app
npm test             # unit tests
npm run check        # svelte-check
```
