title: RealMap 1.0.3 — fix the crash on roads between towns

**Update both the app and the mod** (Mod Hub, or `realmap-mod-1.0.3.zip`), then restart the game.

## Fixes
- **Crash during generation** (« cannot write to read only member 'laneConfigs' », then « lc.segment0 not found »): the step that narrows the roads between towns made the game crash, on maps from 1940 on. Fixed.
- **Roads between towns follow the map's year**: always 2 lanes, as dirt country roads before 1940 and as tarmac country roads from 1940 (the dirt ones no longer exist then). Same route, bridges and tunnels as the game's; town streets and industry access roads are left as they are.

## Installation
Same as 1.0.0: see the [README](https://github.com/Spit8/RealMap#readme). Installed apps update themselves from the Export tab.
