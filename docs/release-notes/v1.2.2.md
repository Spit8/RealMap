title: RealMap 1.2.2 — very large areas no longer stop the preview

**Update the app and the mod** (Mod Hub or `realmap-mod-1.2.2.zip`, then restart the game). The mod only changes its version number, which must match the app's.

## Fixes
- **Very large areas** (a whole country): the preview could stop with « preview: Maximum call stack size exceeded », whatever the map size. The OpenStreetMap data of the area (hundreds of thousands of villages, ponds, roads…) is now handed to the map computation in smaller batches. Thanks for the report!
- **Journal**: an error in the map computation now writes where it happened to the journal. If a problem persists, please send it to us (Journal panel, or the `log.json` of the project).

## Installation
Same as 1.0.0: see the [README](https://github.com/Spit8/RealMap#readme). Installed apps update themselves from the Export tab.
