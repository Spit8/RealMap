title: RealMap 1.0.2 — simple roads, varied town needs

**Update both the app and the mod** (Mod Hub, or `realmap-mod-1.0.2.zip`), then restart the game.

## Changes
- **Roads between towns**: when the game links towns with wide 4-lane country roads, the mod now turns them into simple 2-lane dirt country roads right after (same route, bridges and tunnels); town streets are left as they are.
- **Industries**: like a new game, the map starts with the first-tier industries only (farms, livestock, forest, fishing, clay pit, quarry, oil, refinery, saw mill, brick works…); with the automatic count every one of their chains gets at least one base resource, placed where it exists in reality when possible, like the game guarantees; the total can be slightly higher than the game's count.
- **Town needs**: each town starts with first-tier goods only, like in a new game (meat, vegetables, fish when the map has fishing grounds; bricks, fuel, planks…), spread over the towns like the game does, with a light preference for goods produced on the map. Before, a map with a single complete industrial chain made every town ask for the same good.

## Installation
Same as 1.0.0: see the [README](https://github.com/Spit8/RealMap#readme). Installed apps update themselves from the Export tab.
